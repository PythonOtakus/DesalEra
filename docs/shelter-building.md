> 状态：第一、二阶段已实现（2026-10-07），实现记录见 `docs/progress.md`

> 计划项：P1-5（`docs/plan.md`）

## 问题

现有建造只能搭出“木筏骨架”，搭不出能遮风挡雨的庇护所：

| 限制 | 原因 |
|---|---|
| 一个格子只能放一件 | 占用表是 `Vector2Int → member`，立柱和甲板抢同一格 |
| 只能在甲板高度起建 | 所有构件根节点都在 `BaseDeckY`，没有层的概念 |
| 方向固定 | 甲板永远朝 +X，斜撑永远在 X-Y 平面 |
| 没有面状构件 | 只有杆件，没有屋顶 / 墙 / 地板 |
| “有遮蔽”无判定 | `HudPresenter` 里写死 `false` |
| 遮蔽无玩法意义 | 风暴只加结构风载，不影响角色 |

## 目标（第一阶段）

能跑通一条完整的“搭顶避风暴”闭环：

1. 在甲板上立 4 根立柱  
2. 在柱顶上放屋顶  
3. 站到屋顶下，右上角“有遮蔽”亮起  
4. 风暴来时，暴露在外的角色持续掉体力和生命；遮蔽下不掉

## 设计

### 层（Level）

- `level` ∈ {0, 1, 2}，高度 `y = BaseDeckY + level × StoreyHeightM`，`StoreyHeightM = 3 m`（= 立柱长度）。
- 0 层：沿用旧规则（范围内、与已有结构边相邻）。
- 1 层及以上：**必须有支撑**——构件的根节点处已经存在结构节点（通常是立柱顶）。不能凭空悬在空中。

### 朝向（Facing）

- 四个方向：东(+X) / 北(+Z) / 西(-X) / 南(-Z)，`R` 键循环。
- 只旋转构件偏移量的水平分量：甲板沿朝向铺，斜撑在朝向所在竖直平面内斜向上；立柱、浮筒、淡化器不受影响。

### 插槽（Socket）

占用表从“一个格子一件”改为 `(格点, 层, 插槽)`，同一格点可以同时有立柱和甲板（它们本来就共享节点）：

| 插槽 | 构件 | 说明 |
|---|---|---|
| `V` | 立柱 / 浮筒 / 淡化器 | 每个格点每层一件竖向构件 |
| `BX` / `BZ` | 甲板 | 沿 X / Z 的梁。西 / 南向归一到相邻格点的东 / 北向，同一根梁不会被放两次 |
| `D0`..`D3` | 斜撑 | 四个朝向互不冲突 |
| `R` | 屋顶 | 键为方格西南角格点 |
| `Spawn` | 出生点 | 只占位，不可拆 |

### 屋顶（Roof）

- 只能放在 1 层及以上；覆盖一个 3 m × 3 m 方格，**四个角都必须已有节点**（四根立柱顶）。
- 结构上是方格内的两根交叉对角杆（屋面内 X 撑），有自重、能让柱顶在水平面内不变形；渲染成一块平板。
- 造价：木板 3、废料 1。

### 遮蔽判定

- `RaftState.IsSheltered(pos)`：位置的水平投影落在任意屋顶方格内，且屋顶高于该位置。
- 角色在水里一律不算遮蔽。
- 判定结果每帧写入 `GameBootstrap.PlayerSheltered`，HUD 和生存结算共用。

### 遮蔽的作用

`SurvivalModel.ApplyWeather(minutes, storm, sheltered)`：

| 情况 | 效果 |
|---|---|
| 风暴 + 暴露 | 体力 −30/分钟，生命 −6/分钟（一场风暴约 2 游戏分钟 ≈ −60 体力、−12 生命） |
| 风暴 + 遮蔽 | 无惩罚 |
| 平时 + 遮蔽 | 体力恢复 ×1.5（休整） |

风暴状态条文字附带“暴露中 / 已遮蔽”，暴露时圆点转红。

### 操作

| 输入 | 作用 |
|---|---|
| `1`–`6` | 选构件（新增 6 = 屋顶） |
| `R` | 旋转朝向 |
| `Q` | 切换建造层 0 → 1 → 2 → 0（选屋顶时自动至少为 1 层） |
| 左键 | 在当前层平面上放置 |
| 右键单击 | 拆除当前层上该格点最后放的构件；没有时尝试拆屋顶 |

# 第二阶段：墙、楼板、楼梯、预览、坍塌、风载

## 新构件

| 构件 | 快捷键 | 插槽 | 放置条件 | 结构 | 造价 |
|---|---|---|---|---|---|
| 墙 `Wall` | 7 | `WX` / `WZ`（同甲板，西 / 南向归一到相邻格点） | 两端**都有立柱**（下端节点接地 + 端点之间有存活的竖向杆） | 一根对角杆（板墙当剪力撑），受风面积 9 m² | 木板 3 |
| 楼梯 `Stairs` | 8 | `S0`..`S3` | 底端：0 层贴结构 / 高层接地节点；顶端：相邻格点上一层的立柱顶 | 一根斜杆，渲染为 6 级踏板 + 两侧斜梁 | 木板 4、废料 1 |
| 屋顶 = 楼板 | 6 | `R` | 不变 | 不变 | 不变 |

- 墙占一层高、一格宽，位于格点与朝向方向相邻格点之间的竖直面上。
- 楼梯从 `(格点, L)` 沿朝向爬到 `(格点+朝向, L+1)`，水平 3 m、垂直 3 m。
- 屋顶同时是上一层的楼板：站在上面不算被它遮蔽，再往上一层的屋顶才遮蔽。

## 支撑与“接地”

原先“高处构件根节点有存活杆件”的判定会让两件构件互相撑住（墙撑屋顶角、屋顶撑墙顶）。改为：

- **接地节点**：从所有甲板高度节点和龙骨锚点出发，沿未失效杆件能到达的节点。甲板视为一整块可行走面，因此甲板高度的节点都算地基。
- 高处构件 / 墙 / 楼梯的每个连接点都必须接地；判定时**排除构件自身的杆件**，构件不能自己撑自己。
- 墙额外要求两端各有一根存活的竖向杆（字面意义上的“两端有立柱”）。

## 坍塌连锁

`RaftState.CollapseUnsupported()`：

1. 遍历所有放置记录（出生点除外）。
2. 构件的杆件全部失效（被风暴打断）→ 移除记录，插槽空出可以重建。
3. 高处构件 / 墙 / 楼梯重新做支撑判定（排除自身杆件），不通过 → 杆件失效并移除。
4. 重复直到没有新的坍塌（拆柱 → 楼板塌 → 立在楼板上的上层柱也塌）。
5. **坍塌不退款**；只有主动拆掉的那一件按原规则部分退款。

调用时机：每次拆除之后（`Dismantle` 内）、每次结构分析之后（`GameBootstrap.Reanalyse`，风暴开始 / 结束都会分析）。有构件坍塌时状态条提示“N 个构件失去支撑或损毁，已坍塌”。

## 风载：墙的受风面积

- `Member` 新增 `WindAreaM2` 与 `WindNormal`（水平单位法向）。
- `TrussSolver.ApplyWind` 在原“每节点 风载 × 高度”之外，对每根带面积的杆件加 `风载 / 3 m × 面积 × |法向·风向|`，平分到两端节点，并计入 `_lastWindVector`，重复求解仍幂等。
- 迎风墙（法向平行风向）吃满 9 m²；侧向墙（法向垂直风向）不受风。
- 屋顶 / 楼板水平放置，没有侧向受风面积；**不模拟屋面上掀**。

## 结构求解的两处修正（实现中发现）

1. **刚度组装与杆件朝向有关**：原 `AssembleMember` 把每个方向的刚度乘了“该方向余弦分量之和的平方”。沿坐标轴的杆件恰好等于各向同性弹簧，斜杆却随朝向变化：屋顶两根对角线一根刚度翻倍、一根为零，平静天气就算出 54 kN 的假拉力。改为 `EA/L × (a aᵀ + t (I − a aᵀ))`，`t = TransverseStiffnessFraction = 1`。沿轴杆件结果与原来完全一致，原有支撑测试全部通过。
2. **立柱立在梁中间不连梁**：起始甲板梁长 6 m，中点没有节点，立在 (0,−1) 的立柱脚是孤立节点，柱子和屋顶整片“漂”在结构外，求解报奇异。现在新建节点落在已有杆件中段时会把该杆件一分为二（原杆件保留 id 作前半段，后半段登记到同一构件）。

修正后：只有四柱 + 屋顶的庇护所在风载 6 kN/m 就会断一根屋顶对角杆（屋顶仍在，另一根撑着）；四面各加一组钢斜撑（8 根）后 10 kN/m 无损，14 kN/m 只断起始甲板的一段。**斜撑决定庇护所能否扛过风暴**，与游戏核心卖点一致。

## 角色在楼板 / 楼梯上行走

- `RaftState.TryGetRaisedSurface(pos, maxY)`：返回脚下不高于 `maxY` 的最高抬高面（楼板顶 = 节点 + 0.22 m；楼梯 = 斜线 + 0.12 m，半宽 0.7 m）。
- `PlayerController` 记录当前站立面高度 `SurfaceLocalY`，每帧取“甲板（若在甲板投影内）与 ≤ 当前面 + 0.6 m（`StepUpM`）的最高抬高面”中较高者。
  - 从下方走过楼板不会被抬上去；只能经楼梯上楼。
  - 走出楼板边缘直接落到甲板（或水里），**没有下落动画**。
- 站在高处不在甲板投影内也算“在船上”，不会切换成游泳。
- 遮蔽判定改用站立面高度而不是带浪涌的角色 y。
- `player_teleport` 的 y 用作“目标楼层”提示：(x, 4.8, z) 落到一楼楼板，(x, 1.5, z) 落到甲板。

## 放置预览

- `RaftState.CanPlace(piece, cell, level, facing, out PlacementPlan)`：只校验不改动；无论成败都给出将要生成的杆件几何（插槽 + 线段），`TryPlace` = `CanPlace` + 扣资源 + 提交。
- `PlayerController` 每帧对鼠标下的格点调用 `CanPlace`，暴露 `PreviewPlan` / `PreviewProblem`。
- `BuildPreview` 绘制半透明虚影：可放置为绿色、不可放置为红色；只在目标变化时重建，挂在 RaftRoot 下随浪起伏。
- 建造栏标题行：`构件 · 第 N 层 · 朝向 · 可放置 / 原因`，可放置绿色、拒绝红色、在水中灰色。

## 风暴周期修正

原 `UpdateStorm` 用“下一场风暴开始时间 + 12 s”判断结束，而开始时又把下一场推后 75 s：一场风暴实际持续 87 s，结束当帧下一场就开始，等于永远在刮风暴。现在单独记录结束时间（`stormDurationSeconds = 12`）。
