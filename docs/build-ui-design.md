# 当前版海上生存建造 UI 完整描述
这是一版**符合主流生存建造游戏标准的商业化HUD方案**，以「海上木筏求生+工业建造」为世界观核心，将UI定位为“游戏内的生存工具”而非叠加控件。整体采用「常驻-呼出-临时」三级信息分层，布局完全贴合建造操作的视线流动习惯，视觉统一为旧木板+锈蚀工业金属风格，在保证功能完整的同时最大化保留海面开阔视野。

## 一、整体布局总览
采用生存类游戏经典功能分区，视线流与操作重心高度匹配：
```
┌──────────────────────────────────────────────────┐
│ [左上：航海小地图]        [顶部居中：临时提示消息] │
│                                                  │
│                                                  │
│         海面+木筏平台（中心建造准星+预览）        │
│                                                  │
│                              [右侧中部：建造详情面板] │
│                                                  │
│ [左下：建造快捷栏]  [底部居中：核心状态栏]  [右下：资源速览] │
└──────────────────────────────────────────────────┘
```

## 二、分模块详细设计
### 1. 左上角：航海小地图（常驻一级信息）
- **位置**：屏幕左上角，保留统一安全边距，不贴死边角
- **外观**：方形圆角造型，外圈为旧金属包边，边缘带有轻微锈蚀与海水渍痕迹；面板半透明，不遮挡底层海面视野
- **内容构成**：
  - 中心：玩家木筏平台俯视缩略图，白色三角箭头标注玩家朝向
  - 海面区域：用不同颜色圆点标注附近漂浮资源（棕色=木材、灰色=金属、蓝色=杂物）
  - 边缘：微型罗盘方位标识（N北方向）
  - 底部小字：当前环境参数（浪高、天气状态）
- **功能逻辑**：默认常驻显示，按快捷键可放大为全屏大地图或完全收起

### 2. 底部居中：核心生存状态栏（常驻一级信息）
- **位置**：屏幕底部正中央，位于建造快捷栏上方，是玩家视线移动成本最低的区域
- **布局规则**：横向排列，从左到右严格按生存优先级排序：生命值 → 水分值 → 饱食值 → 耐力值
- **单条结构**：左侧象形图标 + 右侧圆角进度条，数值默认隐藏
- **视觉样式**：窄条型薄木板基底，搭配细金属包边，70%半透明度，最大程度减少对场景的遮挡；进度条带自然渐变质感
- **色彩对应**：生命=红色渐变、水分=蓝色渐变、饱食=橙色渐变、耐力=绿色渐变
- **状态反馈规则**：
  - 70%以上：正常亮度，无额外提示
  - 低于30%：进度条慢速闪烁，数值强制弹出
  - 低于10%：边框变红，同步触发屏幕边缘淡红色晕影，强化生存危机感

### 3. 左下角：建造快捷工具栏（常驻一级信息）
- **位置**：屏幕左下角，底边与状态栏对齐，互不重叠
- **布局**：横向8个槽位，对应键盘快捷键1-8；每个槽位从上到下依次为：快捷键数字 → 象形图标 → 部件名称 → 消耗材料（迷你图标+数字）
- **外观**：槽位为旧金属卡槽+木板底质感，统一圆角
- **状态规则**：
  - 正常可用：常规亮度显示
  - 当前选中：暖金色高亮外框 + 槽位轻微上浮效果，替代违和的冷色调选中
  - 材料不足：整体置灰，消耗数字变为橙红色
  - 图标差异化：立柱、浮筒、斜撑采用高区分度象形图标；两个储物功能分别设计为储物箱、储物架图标，避免重复
- **交互**：悬停时亮度提升、轻微放大；点击有按压回弹动效

### 4. 右下角：资源背包速览（常驻一级信息）
- **位置**：屏幕右下角，与左下角建造栏视觉对称
- **内容**：横向排列4种核心资源——木材、金属、混凝土、绳索；每项由材质小图标 + 持有数量组成
- **外观**：与建造栏同款木板金属基底，保持视觉统一
- **功能逻辑**：
  - 常驻显示，建造时可快速核对数量，无需频繁打开背包
  - 资源不足以支撑当前建造项时，对应数字变红并慢速闪烁
  - 点击可展开完整背包面板

### 5. 右侧中部：建造详情与材料选择面板（二级呼出信息）
- **位置**：屏幕右侧垂直居中，不顶边不贴底，宽度收窄，减少视野遮挡
- **布局（从上到下按信息优先级排序）**：
  1. 标题栏：当前选中建造物名称（如「淡化器」），字号最大加粗
  2. 警告区：存在结构风险时展开，无风险时隐藏；红色警示图标+文字提示，浅红色底色突出
  3. 材料消耗：放大字号突出显示「消耗：4金属 3木板」，是玩家最关心的核心信息
  4. 材料选择列表：木材/钢材/混凝土三个选项，每项=材质图标+名称+核心参数
  5. 操作提示：底部小字浅灰色「ESC 关闭 · 点击选择材料」，弱化处理不抢视线
- **外观**：厚木板拼接面板+金属铆钉包边，边缘做磨损+水渍效果；面板75%不透明度，质感厚重但不臃肿
- **功能逻辑**：仅选中建造项时弹出，平时完全收起，不常驻遮挡视野

### 6. 屏幕中心：建造准星与放置预览（二级呼出信息）
- **位置**：屏幕正中心，进入建造模式显示，非建造模式隐藏
- **形态**：细十字准星，搭配半透明的建造物预览模型
- **状态反馈**：
  - 可正常放置：准星绿色，预览模型呈半透明绿色
  - 不可放置（位置无效/材料不足）：准星红色，预览模型变红
  - 结构风险（会沉筏）：准星橙色，旁侧弹出微型警告标识
- **核心价值**：把建造合法性直接反馈在操作焦点上，无需玩家频繁转头看右侧面板，大幅提升建造流畅度

### 7. 顶部居中：临时提示信息（三级临时信息）
- **位置**：屏幕顶部中央
- **内容**：操作引导、物品获得提示、结构警告等非常驻信息
- **样式**：半透明深色底+白色文字
- **逻辑**：淡入淡出动画，显示3秒后自动消失，绝不常驻遮挡视野

## 三、统一视觉设计规范
### 1. 材质系统
全UI统一两套核心材质，通过厚薄、粗细区分模块层级：
- 面板基底：旧松木纹理，带轻微使用划痕与磨损
- 边框结构：锈蚀黑金属，搭配铆钉、卡槽细节
- 沉浸细节：所有面板边缘做不规则磨损、海水渍痕迹，金属部分加锈斑掉漆效果，让UI像真实在海上使用的工具，而非叠加在画面上的控件

### 2. 色彩语义系统
全局统一色彩规则，杜绝色彩混乱：

| 语义 | 颜色 | 应用场景 |
| :--- | :--- | :--- |
| 主基调 | 深木棕、金属灰、海蓝灰 | 面板、边框、背景 |
| 正常正文 | 米白色 | 普通文字、充足状态 |
| 选中/可用 | 暖金色 | 选中项、可操作高亮 |
| 警告/危险 | 橙红色 | 沉筏提示、低状态、资源不足 |
| 不可用/禁用 | 浅灰色 | 材料不足项、未解锁功能 |
| 状态条固定 | 红/蓝/橙/绿 | 生命/水分/饱食/耐力 |

### 3. 排版规范
- 字体：粗犷工业风无衬线字体，清晰易读，符合生存题材
- 字号层级：标题＞正文＞辅助提示，三级字号严格区分
- 网格对齐：所有模块对齐8px网格，内边距、行间距全局统一
- 圆角规范：所有面板统一8px圆角，边框粗细按模块大小区分

## 四、交互与场景适配
1. **基础交互反馈**：所有可点击元素，悬停时亮度提升、轻微放大；点击时按压回弹效果，搭配轻量木质点击音效
2. **面板动效**：弹出时从对应边缘滑入，0.15秒缓动过渡；收起时反向滑出，杜绝生硬跳转
3. **数值动效**：资源增减、状态条变化均为平滑过渡，数字变动时带轻微跳动反馈
4. **环境适配**：所有常驻文字加1px深色外描边+柔和投影，保证海面强光环境下清晰可见；水下、夜晚场景自动调整UI亮度与色调，保证信息可读

## 五、相对旧版的核心提升
1. **布局彻底重构**：从“左上状态栏+底部建造栏”的错位布局，改为主流生存游戏标准范式，操作视线流更合理
2. **信息层级清晰**：严格按优先级排序信息，核心信息放大突出，次要信息弱化，临时信息自动消失
3. **建造体验升级**：中心准星+预览直接反馈建造合法性，右下角资源速览快速核对，减少视线大幅跳转
4. **视觉完全统一**：全UI统一旧木板+锈蚀金属主题，色彩语义全局一致，摆脱多套风格拼接的割裂感
5. **视野占用优化**：面板收窄、半透明优化，常驻UI均为轻量化设计，最大化保留海面开阔视野
