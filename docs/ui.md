功能布局已跑通（左上状态、底部建造栏、右侧材料面板），但正式体验曾被调试读数打断，与「海洋 / 造船」世界观脱节。评估见会话记录；本文定实现约束与分期。

## 设计（一期）— 摘要

调试默认关（F3）；建造消耗按需显示；操作提示一行；文字描边；圆角 8 / `ScreenMargin` 20。

## 设计（二期）

### 主题面板（2b，以效果图为准）

- 面板基底：`UiFrame.WoodTile` — 宽横铺木板分缝 + `StreamingAssets` 照片木纹，`Image.Type.Tiled`（禁止九宫格拉伸木纹）。
- 边框：`UiFrame.Framed` / `Slot` — 锈蚀金属槽边 + 沿边铆钉，透明中心九宫格叠在木纹上。
- 选中：暖金描边；圆角仍 8。

### 色彩语义（固定）

| 语义 | 色 | 用途 |
|---|---|---|
| 生命 | 红 | 状态条、危险 |
| 饮水 | 蓝 | 状态条 |
| 饱食 | 橙 | 状态条 |
| 耐力 | 绿 | 状态条、可建造 |
| 警告 | 琥珀 | 偏重 / 资源紧 |
| 危险 | 红 | 沉筏 / 不可建造 |
| 选中 | 冷青绿 `Accent` | 焦点，不与资源色抢 |

### 状态栏

- 象形图标：面包 / 水滴 / 心 / 闪电 + 单字标签。
- 数值仅在该条 **&lt; 30%** 时显示。
- 条带圆角井 + 填充高光。

### 建造栏

- 每项用**构件象形图标**（甲板平面、立柱、浮筒桶、斜撑、淡化器、屋顶、墙、楼梯），不再复用资源剪影。
- 消耗：选中或不足时显示；不足用红色。
- 选中：高亮框 + 轻微上浮（一期已有，保留）。

### 材料面板

- 按浮力风险分层：安全正常、偏重琥珀、沉筏置灰 + 警示角标。
- 顶部醒目警告（图标 + 文案）；消耗放大；ESC 提示底部弱化。

### 准星直显

- 屏幕中心小准星：可放置绿、拒绝红；下方一行微型原因（来自 `PreviewProblem` / 可放置）。
- 在水中或无预览时隐藏。

### 非目标（二期不做）

- 真实 PNG 贴图图集、点击音效库、水下滤镜、面板 0.15 s 滑入。

## 验收

- Play 截图：面板呈木色而非纯灰；建造图标形状可区分。
- 打开材料面板时，沉筏材料有灰色 + 警示；顶部警告可见。
- 甲板上选中可放置件时，中心准星为绿色；故意指向非法格时为红色并有短文案。
- 状态条低于 30% 时出现数字。
- EditMode 测试全部通过。
